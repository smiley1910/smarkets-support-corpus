## **30.1 General**

30.1 All markets will be determined using verified information from independent sources, such as national authorities, broadcasters, or other media outlets.

30.2 Bets placed after an event has taken place will be voided. We will seek to establish the time an event has taken place based on information from independent publicly available sources.

30.3 If the political event changes substantially that some or all of the contracts cannot be considered a valid representation of outcomes for an event. For instance, if the coalition of parties changes before an election and the contracts no longer represent the current parties, we reserve the right to void the market.
