## How can we help you?

For the best user experience on Smarkets, please ensure your browser software is up to date with the latest version.

We recommend using the latest version of Google Chrome for optimal performance.

The list of supported browsers is as follows:

*   Google Chrome
*   Mozilla Firefox
*   Microsoft Edge
*   Safari

You can download the most recent software update for your browser for free by [clicking here](http://browsehappy.com/).
