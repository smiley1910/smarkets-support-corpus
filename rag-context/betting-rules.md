# Betting Rules — RAG Context for Support Agents

> **Source:** Smarkets + SBK help centres, scraped June 2026. General rules (1-11) + 49 sport-specific rules + clearly erroneous bets policy.
> **KEY:** Smarkets = EXCHANGE (peer-to-peer). SBK = BOOKMAKER. Rules are nearly identical but contact emails differ.

---

## 1. GENERAL RULES SUMMARY (Rules 1-11)

### Settlement (Rule 4)
- Bets settled ASAP after outcome determined
- Uses official result from governing body on day event concludes
- Subsequent amendments do NOT change settlement
- If no official result: uses independent sources
- Can delay settlement if uncertainty; can void if unresolvable
- Can void/resettle if new info emerges (disqualification, cheating)
- Can reverse incorrect settlement (technical/human error)

### Voiding (Rule 5)
- Smarkets reserves right to void for: suspected fraud, clearly erroneous bets, technical errors
- Can recover funds disbursed in error

### Exceptional Circumstances (Rule 6)
| Scenario | Rule |
|----------|------|
| Event not concluded within 36h of scheduled start | All bets voided |
| Event cancelled | All bets voided |
| Postponed >36h from original start time | All bets voided |
| Change of opponents | All bets voided |
| Change of venue | All bets voided |
| Modified event length | All bets voided |
| Dead heat | Winnings split proportionately |
| Change of surface | Bets STAND (not voided) |

### Dead Heat (Rule 7)
- **'For' (back) bets:** Return = (Stake × (expected winners / actual winners)) × original odds
  - Example: £20 back at 4.0, dead heat with 2 others (3 total): (£20 × 1/3) × 4 = £26.67, profit = £6.67
- **'Against' (lay) bets:** Return = ((1 - (expected winners / actual winners) × original odds) / (original odds - 1)) × original liability
- In multi-winner markets: only contracts tied past last winning position are affected

### In-Play Betting (Rule 8)
- **Betting delay:** 4 seconds (horse racing & darts), 8 seconds (all other events)
- During delay: order pending, not visible in order book, cannot be adjusted/cancelled
- Markets with delay are NOT managed — NOT halted for goals, penalties, red cards
- **Instant Match:** No betting delay; 8-14 second confirmation period; bet can be voided if material event occurs during confirmation
- Material events: goals, penalties, red cards
- Betting after outcome known = voided (rule 8.1.5)
- If market not halted at start: bets matched after off are voided unless market turns in-play later

### Accumulator Rules (Rule 9)
- **Cross-event multiples:** If one selection voided → odds reduced to account for void. If reduction factor applied → accumulator odds reduced proportionally (Rule 9.5.2)
- **Same-event bet builders:** If ANY selection voided or dead heat → ENTIRE multiple voided, stake returned. This applies even if some selections already lost (Rule 9.6.1). Cash out ceases after event turns in-play (9.6.3)
- Horse racing bet builders: full bet voided if reduction factor applied to any included market (9.6.2)

### Keep Bets In-Play (Rule 10)
- KIP = unmatched bet survives when market turns in-play (other unmatched bets cancelled)
- Must be selected individually per bet
- Default = unmatched bets cancelled at halt
- KIP bets keep original queue position
- If matched in-play during confirmation period and material event occurs → bet voided

### Trade Out (Rule 11)
- Trade out = exit bet on individual contract (not overall market)
- NOT guaranteed — can fail if market suspended or odds move
- Unsuccessful request shows reason + may offer new trade out value

## 2. CLEARLY ERRONEOUS BETS POLICY

### Definition
Bets considered erroneous when: obvious significant input error (stake, price, or contract ID) where best price execution cannot account for the error.

### Reporting Window
- **60 minutes** from bet being matched
- Must email support@smarkets.com (Smarkets) or support@getsbk.com (SBK)
- Must be before result decided (unless exceptional circumstances)
- Must include: time bet matched, contract/market, matched price, reason

### Outlier Transactions
- Bets matched at price exceeding ±20% of fair market price
- Can be investigated beyond 60-minute window at Smarkets' discretion

### Liability
- Customer placing erroneous bet remains liable for difference if counter-party has already traded out
- Designed to protect customers, but recovery may not be possible

## 3. SPORT-SPECIFIC QUICK REFERENCE

### Football (Rule 12)
- **90 minutes + stoppage time** — extra time and penalties NOT included unless stated
- Friendly matches: full duration of regular time
- Home team listed first; if incorrectly listed, bets before correction voided
- Abandoned match: voided if not completed within 36h (except unconditionally determined markets, e.g. half-time result if abandoned in 2nd half)
- 3-hour rule: if no info on resumption within 3h of postponement, undetermined bets voided
- **Own goals:** Do NOT count for goalscorer markets (first, last, anytime). Next/previous goal used instead.
- **Cards:** Yellow = 1, straight red = 2, 2 yellows + red = 3, max 3 per player. Cards to non-players (substitutes, managers) don't count.
- Asian Handicap: full goal handicaps ending .0 → void if draw after handicap applied
- Draw No Bet: void if draw
- To Advance: includes extra time and penalties

### Horse Racing (Rule 13)
- **Settlement:** First past the post → then weighed-in result is official. Subsequent appeals ignored.
- **Place markets:**
  - 5-7 runners: 1st, 2nd
  - 8-15 runners: 1st, 2nd, 3rd
  - 16+ (non-handicap): 1st, 2nd, 3rd
  - 16+ (handicap): 1st, 2nd, 3rd, 4th
  - Market name takes precedence if different
- **Non-runners:** Bets on non-runner voided. If places ≥ runners, all bets voided.
- **Reduction Factors (RF):**
  - Win market: RF <2.5% → bets stand unaltered. RF ≥2.5% → matched bets adjusted, unmatched cancelled, market reopened
  - Place market: RF applied to ALL winnings regardless of size, unmatched cancelled
  - Formula: New odds = Old odds × ((100 - RF) / 100). Example: 4.0 × 0.75 = 3.0 (25% RF)
  - Can be applied after race if non-runner discovered later
- **Ante-post:** Bets stand whether horse runs or not (unless balloted out). No RF applied to ante-post.
- Void race / walkover: all markets voided
- Coupled horses: do NOT count for betting purposes (bet on named horse only)

### Tennis (Rule 16)
- First set NOT completed → all bets voided (except determined markets like completed game winners)
- Retirement after first set completed → retiree loses match winner market, opponent wins. Set betting market voided.
- 36-hour postponement rule does NOT apply to tennis
- Change of venue/surface → bets STAND (not voided)
- Championship Tie Break (final set) = counts as 1 game only
- Change to scheduled games/sets → affected game/set betting voided

### Golf (Rule 14)
- If tournament reduced in length, bets stand if outcome determined
- If tournament cancelled/abandoned, outright bets voided unless tournament deemed complete
- Playoff determines winner if tied after regulation
- 36-hole/54-hole markets: if rounds not completed, bets voided unless outcome determined

### Cricket (Rule 15)
- Match result: official result from governing body
- Duckworth-Lewis: bets stand if match officially completed
- Test matches: draw option available; if match not completed, bets voided unless draw impossible
- Limited overs: full quota of overs must be bowled unless match officially decided

### Basketball (Rule 17)
- Includes overtime unless stated otherwise
- Abandoned match: voided if not completed within 36h

### Baseball (Rule 19)
- Match must go 9 innings (or 8.5 if home team winning) for bets to stand
- Called games: official result from governing body
- Extra innings included

### American Football (Rule 20)
- Includes overtime unless stated
- Abandoned: voided if not completed within 36h

### Ice Hockey (Rule 22)
- Includes overtime and shootouts unless stated
- Abandoned: voided if not completed within 36h

### Boxing (Rule 23)
- If fight not completed (draw, technical decision, no contest): 
  - Round betting voided
  - Method of victory: voided if result not determined by KO/TKO/DQ/decision
  - Total rounds: voided if fight doesn't go to scorecards or scheduled end
- Draw: fight winner market voided, round betting voided, total rounds settled on completed rounds

### MMA (Rule 24)
- Similar to boxing
- If fight ends in no contest: all bets voided except those already determined

### Esports (Rule 32)
- Map betting: if map not completed, voided
- Match betting: if match not completed, voided unless format changed (e.g. BO3 → BO1)
- Player names: bet on named player regardless of team changes
- Pause/disconnection: Smarkets may void if unfair advantage

### SBK-Specific Notes

- SBK offers multiples, accumulators, bet builders
- SBK has its own cash out feature (different from Smarkets trade out)
- SBK support email: support@getsbk.com
- SBK betting rules mirror Smarkets rules 1-11 but apply to bookmaker bets
- SBK has 24 sport-specific rule sets (no Fantasy Football; Smarkets has 25)
- SBK Gaelic Games is rule 35; Smarkets is rule 36

## 5. COMMON SETTLEMENT QUERIES

### "Why was my bet voided?"
Check: Was the event abandoned/cancelled/postponed >36h? Was there a non-runner (RF)? Was it a bet builder with a voided leg? Was the bet clearly erroneous? Was the market settled incorrectly and resettled?

### "Why was my horse racing bet adjusted?"
Reduction factor applied. If RF ≥2.5% in win market, odds reduced. In place market, ANY RF adjusts winnings. Check if horse was a non-runner.

### "Why didn't my football bet include extra time?"
Default is 90 minutes + stoppage. Only "To Advance" and explicitly stated markets include extra time/penalties.

### "Why was my accumulator voided?"
If same-event bet builder: ANY voided selection voids entire bet. If cross-event: voided selection reduces odds, bet continues.

### "When will my bet settle?"
ASAP after outcome determined. May be delayed if uncertainty. Horse racing: first past the post then weighed-in result.

### "My tennis player retired, what happens?"
If after first set completed: retiree loses match winner, opponent wins. Set betting voided. If before first set completed: all voided.

## 6. REDUCTION FACTOR REFERENCE

### Formula
```
New odds = Old odds × ((100 - RF) / 100)
```

### Examples
| Original Odds | RF | New Odds |
|--------------|-----|---------|
| 4.0 | 25% | 3.0 |
| 4.0 | 50% | 2.0 |
| 10.0 | 10% | 9.0 |
| 2.0 | 2.5% | 1.95 |

### Application Rules
| Market | RF < 2.5% | RF ≥ 2.5% |
|--------|-----------|-----------|
| Win | Bets stand unaltered | Matched bets adjusted, unmatched cancelled, market reopened |
| Place | All winnings adjusted (any RF) | All winnings adjusted, unmatched cancelled |

### Accumulators
Cross-event: RF reduces accumulator odds proportionally
Same-event bet builder (horse racing): entire bet voided if RF applied
