Matched volume is available through the API. GET /v3/markets/{market_ids}/volumes/ returns the traded volume for each market you request, measured in GBP and calculated as the back stake on the back side plus the liability on the lay side. That is the same volume figure shown on the Smarkets website. Volume is returned per market for up to 300 market ids per request. The contract level figure available is the last traded price with its execution timestamp, from GET /v3/markets/{market_ids}/last_executed_prices/. The endpoints you tried cover different data. The events states endpoint returns lifecycle state only. Market state is a field on the market objects returned by GET /v3/events/{event_ids}/markets/, not a separate markets states route, and there is no trades route, so those paths return 404.

The API is REST only. We don't offer websockets or a streaming feed, so there is no websocket URL or authentication method for one. There are no subscription levels that unlock streaming. The access you have is the full API and it already includes the volume endpoint above, and no level of access provides a streaming feed. Price and volume updates are retrieved by polling the endpoints above, within your rate limits. If you saw a streaming endpoint documented somewhere, send me the link and I'll tell you whether it applies to our API.

The API is provided for viewing market prices and placing bets on your Smarkets account. Section 5 of the API terms states: "Additionally, usage of the API or its data to benchmark markets, prices, liquidity or systems is not permitted." The fair usage terms treat using the API to monitor markets as a breach, and Sections 6.1 and 7 cover data extraction without commensurate trading volumes. The benchmarking restriction applies to the comparison itself, whether or not you also place bets. A tool that compares our liquidity against other exchanges falls within those restrictions, so it is not a use the access permits. To be precise about what this covers, the restriction is on using the API as a monitoring or benchmarking feed rather than as a trading tool, so trading on your Smarkets account is unaffected.

If the access is not a fit for your purposes, under Section 3 your setup fee will be refunded if you permanently withdraw from API usage within the first 60 days. If you'd like to talk through whether the access still fits before deciding, reply to this email.
