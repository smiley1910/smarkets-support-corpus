# Change the odds format

## We offer three odds formats to choose from:

*   Decimal (default)
*   Percentage
*   American

## Change odds format using website:

You can change the odds format by clicking on the balance dropdown.

![Image 4: Screenshot_from_2020-03-31_16-14-32.png](https://help.smarkets.com/hc/article_attachments/360007460978/Screenshot_from_2020-03-31_16-14-32.png)

## Change odds format using the app:

Change odds format using website:

You can change the odds format on the app by going to Account settings > General settings. You can change the format by clicking on the "select odds format" drop-down.
