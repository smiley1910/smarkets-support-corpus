# Smarkets API Documentation & Resources

This page provides the essential technical resources for developers and traders looking to integrate with the Smarkets exchange.

*   📘 [**Onboarding Information**](https://help.smarkets.com/hc/en-gb/articles/34697834941085-Smarkets-API-Access-Integration-T-Cs)– Everything you need to know to apply.
*   🛠️ [**API Request Form**](https://support.smarkets.com/p/6MLL-PL7/api-request-form) – Request access to get your API access.

*   📁 [**Full API Reference Guide**](https://docs.smarkets.com/) – Detailed endpoint specification and authentication methods.

* * *

### **Technical Overview**

The Smarkets API provides programmatic access to our exchange engine, enabling:

*   **Market Data:** Real-time access to order books and price history.

*   **Order Management:** Automated placing, cancelling, and updating of bets.

*   **Account Management:** Real-time balance tracking and transaction history.
